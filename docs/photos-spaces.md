# Визуалы сада, света, керамики, домиков и студии звукозаписи

Все десять изображений созданы с помощью OpenAI ImageGen специально для этого портфолио в отдельных генерациях. Оптимизированные версии в WebP хранятся локально в `public/media/`.

| Файл | Содержание |
| --- | --- |
| landscape/hero.webp | Сад с извилистой гравийной тропой, многолетниками и злаками |
| landscape/detail.webp | Бордовые соцветия кровохлёбки и травы в боковом свете |
| lighting/hero.webp | Латунные подвесные светильники на фоне бордовой стены |
| lighting/detail.webp | Шлифованная латунь и молочный стеклянный рассеиватель |
| ceramics/hero.webp | Керамические тарелки и кувшин в мастерской |
| ceramics/detail.webp | Руки гончара формируют чашу на круге |
| cabins/hero.webp | Деревянный домик у озера в вечернем сосновом лесу |
| cabins/detail.webp | Спальня с деревянной отделкой и панорамным окном |
| acoustics/hero.webp | Микшерный пульт и мониторы в контрольной комнате |
| acoustics/detail.webp | Вокальный микрофон с поп-фильтром в акустической кабине |
