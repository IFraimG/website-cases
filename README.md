# Фолио

Один статический проект на Astro и обычном CSS. Главная объединяет 21 коммерческий концепт с фильтром по темам. Каталог и каждый кейс имеют две статические языковые версии. Бренды, проекты, характеристики, цены и расписание вымышлены. Демо работает локально.

## Запуск

Для воспроизведения сборки используйте Node.js 20.20 или 22 LTS и npm. Из корня проекта выполните

```sh
npm ci
npm run dev
```

Перейдите по локальному адресу из терминала. Для просмотра production-версии

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4321
```

Astro сохраняет готовый сайт в `dist/`.

## Языки

Английский открывается по умолчанию на `/` и на маршрутах без префикса. Русский каталог доступен на `/ru/`. У каждого адреса из таблицы есть русская версия с этим префиксом, например `/ru/lighting/`. Переключатель EN / RU в шапке ведёт к тому же кейсу и сохраняет якорь раздела. Ссылки из каталога и обратно сохраняют выбранный язык. Язык определяется адресом и сохраняется при обновлении или пересылке ссылки.

Статическая сборка содержит 884 HTML-страницы (главная витрина + 21 полноценный многостраничный сайт по 21 странице каждый в EN и RU), включая заголовки документа, подписи полей, описания изображений и доступные имена на языке страницы. Каждый из 21 сайта расширен до 13 типовых разделов (Главная, Каталог/услуги с фильтрами, 4 детальные карточки с галереей и формой, Проекты/кейсы, 3 детальные страницы проектов с таблицей этапов, Партнёрам/инвесторам, Интерактивная заявка/расчёт, О компании, Команда, Журнал + 3 полные статьи, Спецпрограмма, Контакты с картой и формой, Карьера с откликом). Данные многостраничного расширения хранятся в `src/data/sites/`. Для исходных шести главных страниц переводы хранятся в `src/i18n/legacy-en.json`, для остальных пятнадцати — в `src/data/studios/`.

## Изображения и шрифты

- Архитектура, автомобиль и мебель созданы с помощью OpenAI ImageGen специально для этих концептов. Для сравнения покрытия использованы два изображения одного ракурса. [Перечень с описаниями](docs/photos-1.md)
- Для клиники и квартала использованы фотографии Pexels. [Фотографы, страницы оригиналов и лицензия](docs/photos-2.md)
- Кадры садов, освещения, керамики, домиков и студии звукозаписи созданы в ImageGen. [Сюжеты и файлы](docs/photos-spaces.md)
- Фотографии для пяти транспортных проектов взяты с Pexels. [Авторы, оригиналы и лицензия](docs/photos-motion.md)
- Оправы, зал для пилатеса, банный дом, обжарочная и коворкинг иллюстрированы кадрами из ImageGen. [Сведения о генерации](docs/photos-studios.md)
- Оптимизированные файлы находятся в `public/media/`, превью из браузера — в `public/previews/`. Шрифты Inter, PT Serif и IBM Plex Mono поставляются локально через пакеты Fontsource. Лицензии шрифтов включены в пакеты.
- Складской интерфейс построен на HTML/CSS. Три векторные планировки отрисованы компонентом `src/components/Plan.astro` по размерам 6 × 5, 8 × 6 и 10 × 7 м.

## Браузерная проверка и снимки

Запустите production-сервер на порту 4321. Во втором терминале выполните

```sh
npm run check:browser
```

Скрипт использует установленный Google Chrome на macOS. На других платформах установите браузер командой `npx playwright install chromium` или задайте путь к исполняемому файлу через `CHROME_PATH`. Для другого адреса сервера предусмотрен `PREVIEW_URL`.

Скрипт проверяет 44 страницы при ширине 1440 и 390 px. Для каждого из 88 сочетаний он проверяет HTTP-ответ, язык документа, изображения, горизонтальное переполнение, консоль и ошибки JavaScript. В браузере выполняются основные взаимодействия и переход на второй язык и обратно. Для калькуляторов проверяются результат и диапазон ввода, для демозаписи — обязательное поле и локальное подтверждение.

Английские полностраничные PNG находятся в `screenshots/`, русские — в `screenshots/ru/`. Формат имени — `<маршрут>-<ширина>.png`. Сравнение первых экранов всех 21 сайтов хранится в `screenshots/first-screens.png`, журнал проверок — в `screenshots/checks.json`.

После изменения дизайна соберите проект и запустите preview. Чтобы обновить обложки каталога в обеих локалях, выполните `npm run check:browser -- --previews`, затем повторите сборку и полный прогон. Для проверки отдельных кейсов можно передать список через `CHECK_ROUTES=lighting,ceramics npm run check:browser`.
